- Fixed: `verify npm-tarball` no longer fails a publish that succeeded. It read npm's packument through `npm view`, which npm caches for five minutes, so a read just after publish kept getting a copy without the new version. It now reads the uncached per-version document (`GET /<name>/<version>`) and retries for up to about 12 minutes, since npm can take several minutes to record a version. #716. (verified by: integration, e2e/CLI)
