- Fixed: the dogfood release (`release-npm.yml`) no longer fails with `PIOT_PUBLISH_EMPTY_PLAN` on pushes that touch no globbed file. `putitoutthere.toml` globbed `dist-action/**`, a path that is gitignored on main and exists only on fold-shaped tag commits — so every plan-time diff against a real `putitoutthere-v*` tag listed it as phantom *deletions*, spuriously cascading a release; the workflow gate passed, and `publish`'s post-fold re-plan (with a byte-identical bundle restored) then correctly came up empty and threw (run 30940944558's trigger, run 30940206119 on main @ 8285c46, the first push whose files matched no other glob). The `dist-action/**` entry is removed: the bundle is generated from `packages/engine/src/**`, which is already globbed, so no real change class loses its cascade — and a no-globbed-file push now plans empty in *both* phases, letting the gate skip publish as designed. Self-release config only; consumer configs are untouched (though the same rule applies to any consumer glob naming a path that exists only on tag commits). #607.
