- Fixed: a `napi` or `bundled-cli` npm package is no longer published before its platform packages are visible on the registry. npm could serve the main package while a platform package still 404'd, and an install in that window skipped the missing `optionalDependency` without an error, leaving no native addon (`npx` then cached the broken install). After publishing the platform packages, `publish` now reads each one's per-version document (`GET /<name>/<version>`), retrying for up to about 12 minutes, and publishes the main package only once all of them resolve. If one never does, the main package is not published and the error names the missing package. #733. (verified by: integration, e2e/CLI, unit/ubuntu-latest)
