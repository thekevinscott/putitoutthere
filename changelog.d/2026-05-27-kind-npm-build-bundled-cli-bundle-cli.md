- Fixed: `kind = "npm"` `build = "bundled-cli"` `bundle_cli — add Rust target`, `cargo build`, and `stage binary` steps now correctly map npm-flavor triples (`linux-x64-gnu`, `darwin-arm64`, `win32-x64-msvc`, …) to their Rust equivalents (`x86_64-unknown-linux-musl`, `aarch64-apple-darwin`, `x86_64-pc-windows-msvc`, …) before calling `rustup target add` and `cargo build --target`. Previously the bare `${TARGET//-linux-gnu/-linux-musl}` substitution was a no-op on npm-flavor triples — the substring `-linux-gnu` does not appear in `linux-x64-gnu` — so `rustup` received the raw npm triple and all five bundle_cli matrix rows failed immediately: `error: toolchain '...' does not support target 'linux-x64-gnu'`.
