- Added: `putitoutthere verify wheel` — the pypi-side sibling of the verify family (#443, #449). Asserts a built maturin artifact under `<path>/dist` carries the planned version: a wheel row's first `*.whl` must have a `*.dist-info/METADATA` `Version:` equal to `--version`, and an sdist row (`--target sdist`) must produce a `*.tar.gz` whose filename contains it. Absorbs the inline "Verify wheel/sdist version matches matrix.version" bash block the reusable e2e workflow (`e2e-fixture-job.yml`, #276) carried as untested bash — same file selection, same `::error::`/`ok wheel:`/`ok sdist:` messages, same exit code — into one colocated-tested engine command. The wheel's METADATA is read with a dependency-free pure-Node zip reader (no `unzip`), so the command runs on every platform the maturin matrix builds on, Windows included. Takes `--path <pkg-dir>`, `--version <planned>`, and `--target <sdist|triple>`. #450.
