- Added: `putitoutthere resolve`, a subcommand emitting [willfire](https://github.com/thekevinscott/willfire)'s callback map for this repo's e2e plan job (epic thekevinscott/willfire#152). From a checkout of this repo it prints one JSON object keyed `thekevinscott/putitoutthere/.github/workflows/e2e-fixture-job.yml:plan` (key format frozen on thekevinscott/willfire#153) with one entry per fixture under `packages/engine/tests/fixtures`, each carrying the exact `matrix` / `has_pypi` strings the live plan job writes to `$GITHUB_OUTPUT` (matrix version pinned `0.0.0` so output is deterministic). All matrix computation is delegated to the `piot-ci fixture-matrix` core — no parallel plan logic — and runs offline with no arguments and no env inputs. From a checkout without the e2e workflow it prints `{}`; any internal failure exits non-zero with no partial map. #683.
