- Added: optional `manylinux` key on `kind = "pypi"` / `build = "maturin"` packages — the linux wheel platform-tag baseline (`"2_28"`, legacy `"1"`/`"2010"`/`"2014"`, `"auto"`, or `"musllinux_X_Y"`). Without it, linux wheels build directly on the runner and are tagged with *its* glibc (`manylinux_2_39` on ubuntu-24.04), so `pip` on any older-glibc host silently falls back to the sdist (thekevinscott/dirsql#818). The planner stamps the value on each per-target linux wheel row of the matching libc family (`manylinux*` → `-gnu` triples, `musllinux_*` → `-musl` triples), and both maturin build workflows (`_matrix.yml`, `e2e-fixture-job.yml`) forward it to `PyO3/maturin-action`'s `manylinux` input, which builds inside the matching `quay.io/pypa` container and enables maturin's auditwheel compliance check. `verify wheel` gains a `--manylinux` flag asserting the produced wheel filename carries the requested tag. Omitting the key preserves the host-build behavior exactly; non-linux targets and the sdist are untouched. #610.
