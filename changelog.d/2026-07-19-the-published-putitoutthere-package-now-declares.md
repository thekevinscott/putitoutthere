- Changed: **BREAKING** — the published `putitoutthere` package now declares an `engines.node` of `>=24`, raised from `>=20`. Every CI leg already ran Node 24, so `>=20` was an unverified claim rather than a supported configuration: nothing in the matrix exercised Node 20, and a consumer taking the declared floor at face value had nothing behind it. This narrows the published contract to what is actually tested. Installing under Node 20–23 now emits an `EBADENGINE` warning under npm and fails outright under pnpm. Consumers below Node 24 should upgrade the runtime; Node 20 is past end-of-life. See [migration notes](../migrations.d/2026-07-19-engines-node-floor-raised-to-24.md). #589.
