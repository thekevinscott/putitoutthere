- Fixed: `publish` no longer tags HEAD for an already-published, untagged version when HEAD carries changes that version never shipped. Auto-heal (#407) now tags HEAD only when at most one commit since the package's last tag touches it (its globs, or a `depends_on` package's). With more than one, it fails with `[PIOT_HEAL_UNRELEASED_CHANGES]`, naming `<name>@<version>` and telling the operator to tag the published commit by hand or with `reconcile --expect` from that commit, then rerun. See [migration notes](../migrations.d/2026-10-20-auto-heal-refuses-to-tag-head-over-unreleased-changes.md). #776. (verified by: integration, e2e/CLI, unit/ubuntu-latest)
